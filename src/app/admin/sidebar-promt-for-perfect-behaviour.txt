## Prompt: Replicate Digi Carotene app-shell sidebar expand/collapse (exact behavior)

Build a desktop sidebar expand/collapse system that matches this app’s shell exactly. Do not invent alternate patterns.

### Architecture & state

1. **Owner of collapse state is the shell layout**, not the sidebar.
   - In `AppShellLayout`, keep:
     - `const [isSidebarCollapsed, setIsSidebarCollapsed] = useState(false);`
     - `const [isMobileNavOpen, setIsMobileNavOpen] = useState(false);`
   - Pass `collapsed={isSidebarCollapsed}` into `ShellSidebar`.
   - Default is **expanded** (`false`).

2. **Header toggle (desktop only)**
   In the top header (`h-16`), render a button that toggles collapse:
   - `variant="secondary"`
   - Classes: `hidden size-9 items-center justify-center rounded-xl md:inline-flex`
   - Icon: Lucide `Menu` with `className="size-4"`
   - `onClick={() => setIsSidebarCollapsed((prev) => !prev)}`
   - `aria-label={isSidebarCollapsed ? "Expand sidebar" : "Collapse sidebar"}`
   - Visible only from `md` and up. Below `md`, a separate hamburger opens a mobile sheet (not the collapse).

3. **Mobile is separate**
   - Below `md`, sidebar width is forced to `w-0` (not `display:none`) so the main content fills the viewport.
   - Mobile nav uses a left `Sheet` at `w-64 max-w-[85vw]` with the same sidebar content but always `collapsed={false}`.
   - Closing the sheet happens via `onNavigate` on links.

### Sidebar shell (aside) — widths, border, motion

Use Framer Motion `motion.aside` with this exact mount animation from `SHELL_SIDEBAR_MOTION`:

```ts
MOTION_EASE = [0.22, 1, 0.36, 1]

SHELL_SIDEBAR_MOTION = {
  initial: { opacity: 0, x: -20 },
  animate: { opacity: 1, x: 0 },
  transition: { duration: 0.38, ease: MOTION_EASE },
}
```

Aside classes (exact):

- Base: `min-h-0 w-0 shrink-0 overflow-hidden border-0 bg-sidebar text-sidebar-foreground`
- Width animation (CSS, not Framer width):
  `transition-[width] duration-500 ease-[cubic-bezier(0.32,0.72,0,1)]`
- Desktop border: `md:border-r md:border-sidebar-border/80`
- Expanded width: `md:w-64` (256px)
- Collapsed width: `md:w-20` (80px)
- Inner content wrapper: `hidden h-full md:block` (desktop only)

Wrap the aside in `TooltipProvider` (Radix; default `delayDuration={0}`).

Header uses separate Framer motion (`SHELL_HEADER_MOTION`: fade/slide from `y: -14`, duration `0.38`, delay `0.06`) — do not couple header motion to width.

### Tooltips when collapsed (required for every leaf link)

When `collapsed === true`, wrap each nav link:

```tsx
<Tooltip>
  <TooltipTrigger asChild>
    <div className="w-full">{navLinkEl}</div>
  </TooltipTrigger>
  <TooltipContent side="right" sideOffset={10}>
    <p className="font-medium">{item.label}</p>
  </TooltipContent>
</Tooltip>
```

Critical details:

- Tooltip only when collapsed; expanded shows no tooltip.
- Trigger wrapper is a full-width `div` (`asChild`) so the whole row is hoverable.
- `side="right"`, `sideOffset={10}` (10px gap from sidebar edge).
- Tooltip content uses the shared tooltip styles: `bg-foreground text-background`, `px-3 py-1.5`, `text-xs`, `rounded-md`, with arrow.
- Provider delay is `0` so labels appear immediately on hover.

- Icon `size-4`; label `min-w-0 flex-1 truncate text-left`

- Children container: `relative ml-4 space-y-0.5 border-l border-sidebar-border/70 py-0.5 pl-3`
- Child links: `rounded-xl px-3 py-2 text-sm`

  - Inactive: `text-sidebar-foreground/65 hover:bg-secondary/70 hover:text-secondary-foreground`

**Collapsed sidebar:**

- Groups collapse to a single icon link (parent route) with the same tooltip behavior as leaf links.
- Do **not** show nested children or chevron when collapsed.
- Group is “active” if any child path matches.
